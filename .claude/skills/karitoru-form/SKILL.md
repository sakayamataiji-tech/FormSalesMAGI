# karitoru-form ── フォーム営業 共通ルール

このスキルは「マギシステム」の全エージェント（opener / replier / closer / judge）が共有する憲法です。
起草者はこのルールに従って書き、裁判官はこのルールで裁きます。

---

## 1. 絶対条件（1つでも欠けたら失格）

| # | 条件 | 判定方法 |
|---|------|----------|
| A1 | **本文は400字以内** | 本文（宛名行〜署名行まで）の文字数。改行と空白は数えない。全角・半角ともに1文字として数える。 |
| A2 | **件名に【】と数字を入れる** | 件名の中に `【` と `】` の組と、算用数字（例: 3, 30, 2026）が最低1つ含まれること。数字は「3社」「30%」「1件」「10分」など具体を示すものにする。 |
| A3 | **文頭は「〇〇部 〇〇様」** | 本文の1行目が `{部署名} {担当者名}様` で始まること。担当者名が不明な場合のみ `{部署名} ご担当者様` を許容。会社名だけの宛名（「株式会社〇〇 御中」）は失格。 |

- 字数は「たぶん大丈夫」で済ませない。起草者は必ず自分で数え、出力の自己チェック欄に数値を書く。
- 裁判官は必ず機械的に数え直す（Bashが使えるなら `python3 -c` で計測する）。

---

## 2. 品質条件（採点対象・全て満たすのが前提）

| # | 条件 | 何をすれば満たしたことになるか |
|---|------|------------------------------|
| Q1 | **パーソナライズ必須** | 相手の社名・事業内容・強み・直近の動き（CSVの「事業内容」「課題仮説」）に本文で具体的に触れる。社名を差し替えたら成立しなくなる一文が最低1つあること。 |
| Q2 | **自社が何者かを明示** | §4-1 の会社紹介文を一字一句そのまま本文に入れる。実績数字は使わない（§4-2 参照、Evidence必須ではない）。 |
| Q3 | **なぜ今動くべきか** | 4つの壁を潰す。**不信**（誰？→§4-1の紹介文そのものが担保）、**不要**（うちには要らない→課題仮説への当て込み）、**不適**（うちには合わない→0→1相談・SESどちらの形でも対応できると示す）、**不急**（今じゃない→期限・季節性・機会損失）。特に「不急」を潰す一文は必須。 |
| Q4 | **アクションは1つに絞る** | 相手に求める行動は1つだけ。§4-2の固定CTA「ご興味があれば、「興味あり」とご返信ください。」を本文末尾にそのまま使う。資料請求・打ち合わせ提案など第二の選択肢を並べない。URLを複数貼らない。 |
| Q5 | **FAB+E** | Feature（特徴）→ Advantage（利点）→ Benefit（相手にとっての利益）を1本の線でつなぐ。Evidence（実績・事例）は §4-2 の通りなしでよい。特徴だけ並べて終わらない。 |
| Q6 | **USPを一言で示す** | §4-2 の「USP一言」をベースに、独自性を一言で言い切る。「唯一」「業界No.1」などの排他的表現は使わない。 |

## 3. 文体・禁止事項

- 敬体（です・ます）。営業臭い煽り（「今すぐ！」「限定！」の連呼）は禁止。
- 1文は60字以内を目安。段落は3〜5個。改行で読みやすく。
- 相手を見下す表現、競合他社の名指し批判、根拠のない「業界No.1」は禁止。
- **§4 にない数字・固有名詞・事例を創作しない。** 足りない場合は数字を使わない書き方に逃げる。
- 絵文字・記号の乱用禁止。件名の【】は1組まで。
- 「唯一」「業界No.1」「日本最大」等の排他的・断定的な誇大表現は禁止（§4-4参照）。
- 「◯文字だけ返信してください」のような文字数を指定する言い方は禁止（クライアントから違和感を指摘済み）。CTAは §4-2 の固定文「ご興味があれば、「興味あり」とご返信ください。」を使う。
- 「お忙しいところ恐縮ですが」などの定型枕詞で冒頭を埋めない。冒頭2行で「あなた宛て」だと分からせる。

## 4. 自社プロフィール（差し込み用データ）

> **現在の送信元: 株式会社レイハウオリ（Lei Hau'oli）**
> 2026-09-18、クライアント本人からのフィードバックにより全面差し替え。**以前の版にあった「2008年設立」「エンジニア約40名」「国内最大級の美容予約サービス」「大手BtoC直請け」「唯一の開発支援会社」「SaaS管理画面の刷新が得意領域」は、社内未確認の推測情報であり事実と異なる可能性があるとして使用禁止になった。** 今後はこの節の内容だけを使う。

### 4-1. 会社紹介文（固定・一字一句そのまま使用）

以下の段落は **クライアント本人が指定した確定文** です。起草者はこれを要約・言い換え・誇張・数字の追加をせず、**そのまま本文に挿入する**（改行位置の調整は可）。この段落自体で Q2（自社明示）を満たしたものとみなす。

```
私たち株式会社レイハウオリは、Web領域を中心に、ITリソースや専門人材が不足しているお客様を支援しています。
社内には、エンジニア・デザイナー・ディレクター・PMなど、各分野のエキスパートが在籍しています。
「何を作ればいいのかわからない」「IT周りをまとめて任せたい」といった0→1のご相談から、「社員の退職に伴うリソース不足を補いたい」といったSESのご要望まで、課題やフェーズに応じて幅広く対応しています。
```

- 全角で約200字。400字の本文予算のうち約半分をこの段落が占める。他の要素（パーソナライズ・なぜ今・CTA）は残り約200字に収める。
- 「フロントエンド特化」「SES専業」など、この段落にない限定は付け加えない。商材はWeb領域のIT人材支援全般（0→1の制作・ディレクション相談からSESまで）であり、SESだけの会社ではない。
- 個社の課題仮説がSES寄り（人材不足の補填）ならその流れを強調してよいが、0→1相談（デザイン・ディレクション・PM含む）の側面を完全に消さない。

### 4-2. USP一言・FAB+E（この段落の中だけで表現する）

| 項目 | 値 |
|------|----|
| USP一言 | 「0→1のWeb制作相談から、退職者補填のSESまで、エンジニア・デザイナー・ディレクター・PMが揃うワンストップ体制で応える」（4-1の段落から言い換えずに抽出する。新しい形容詞・数字を足さない） |
| Feature | エンジニア・デザイナー・ディレクター・PMなど各分野のエキスパートが在籍 |
| Advantage | 0→1の相談からリソース不足の補填まで、案件のフェーズや形に合わせて一括で頼める（採用・発注先を分けずに済む） |
| Benefit | 相手企業は「まず何を誰に頼めばいいか」を自分で切り分けずに済み、課題を持ち込むだけで動き出せる |
| Evidence（実績） | **なし。数値・社名・事例は一切使わない。** Q5のEvidenceはこの節では「必須」ではなく「あれば強いが、ないなら省略してよい」の扱いに緩和する。裁判官はEvidence欠落を理由に減点しない。 |
| 得意領域 | Web領域全般（制作・開発・デザイン・ディレクション・SESによる人材補填）。特定の技術スタックや業界への限定はしない。 |
| 主なCTA | **標準形（固定）**: 「ご興味があれば、「興味あり」とご返信ください。」を本文末尾（署名の直前）にそのまま使う。**文字数を指定する言い方（「◯文字だけ」等）は使わない**（クライアントから違和感を指摘済み）。返信してほしい言葉を「興味あり」と明示するだけにとどめる。CTAの直前に置く一文（「なぜ今」の締め）は各社パーソナライズしてよいが、CTA文そのものは変えない。 |

### 4-3. 署名（固定・一字一句そのまま使用）

```
株式会社Lei Hau'oli
（tel）050-5497-3411
（mail）ml.account-sales@leihauoli.com
```

- 「〇〇（要確認）」「連絡先 要確認」のようなプレースホルダーは**絶対に出力してはならない**。担当者個人名は使わず、この3行をそのまま署名として使う。
- 会社紹介文（4-1）と署名（4-3）を合わせるとそれだけで約230字。残り約170字でパーソナライズ・なぜ今・CTAを書く必要がある。字数が厳しい場合は、4-1の3文のうち最も汎用的な1文（例: 中央の「社内には〜」の文）を削ってよいが、0→1とSESの両方に触れる部分（1文目・3文目）は残す。

### 4-4. 使ってはいけない情報

単価・稼働率・契約継続率・参画までの日数・取引社数・設立年・エンジニア人数・特定の導入事例（美容予約サービス等）・「唯一」「業界No.1」のような排他的表現。§4-1 と §4-2 にない実績・数字・固有名詞は創作禁止。

## 5. 出力フォーマット（起草者 opener / replier / closer 共通）

起草者は必ず以下の形式で**1案だけ**出力する。余計な前置き・解説は書かない。

```
## 件名
【...】...（数字を含む）

## 本文
{部署名} {担当者名}様

（本文）

（署名）

## 狙い
- この案が最も強い指標: 開封率 / 返信率 / 契約率 のどれか
- 仕掛けの要点（3行以内）

## 自己チェック
- 本文文字数: NNN 字（改行・空白除く）
- A1 400字以内: OK/NG
- A2 件名に【】と数字: OK/NG
- A3 文頭「〇〇部 〇〇様」: OK/NG
- Q1〜Q6: それぞれ OK/弱い/NG と、根拠となる本文の該当箇所
```

---

## 6. 起草前の3つの問い

書き始める前に必ず自問する。

1. この会社の担当者が、**社名を伏せて読んでも自社宛てだと分かるか**。
2. 「今週中に返信しないと損をする理由」を**1文で言えるか**。
3. 相手が取るべき行動は**1つだけ**か。

3つとも Yes になるまで書き始めない。
